# 일일 안전보건 현장관리 · 김해신문센트럴아이파크

링크만 열면 로그인 없이 작업을 등록하는 현장 앱입니다. 화면은 GitHub Pages, 저장은 구글시트(Apps Script)가 맡습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 (대시보드 · 작업현황 · 작업등록 · 관리) |
| `config.js` | 구글시트 Apps Script 주소 한 줄 |
| `Code.gs` | 구글시트에 붙여 넣는 저장용 스크립트 (GitHub에는 참고용) |

## 1. 구글시트에 스크립트 붙이기 (처음 한 번)

1. 작업 현황 구글시트를 열고 **확장 프로그램 → Apps Script**를 누릅니다.
2. 편집기에 있던 내용을 지우고 `Code.gs` 내용을 통째로 붙여 넣습니다.
3. 맨 위 `ADMIN_PASSWORD = '1234'`를 원하는 관리 비밀번호로 바꾸고 저장(Ctrl+S)합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형: **웹 앱**
   - 다음 사용자 인증정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 구글 계정 권한을 허용합니다. ("확인되지 않은 앱" 화면이 나오면 고급 → 이동)
6. 나오는 **웹 앱 URL**(…/exec 로 끝남)을 복사합니다.

## 2. GitHub에 올리기

1. 저장소 `an901207/Sinmun-ipark`에서 `config.js`를 열고, 따옴표 안에 위 URL을 붙여 넣습니다.
   ```js
   window.SOS_API = "https://script.google.com/macros/s/……/exec";
   ```
2. `index.html`, `config.js`를 저장소에 올립니다(기존 index.html은 덮어쓰기).
3. 1~2분 뒤 https://an901207.github.io/Sinmun-ipark/ 를 새로고침합니다.

## 3. 처음 설정

- 관리 탭 → 비밀번호 입력 → 동 목록 · 공종 · 배치도 이미지 올리기.
- 배치도 이미지는 구글 드라이브 `SOS 배치도` 폴더에 저장됩니다.

## 스크립트를 고친 뒤에는

Apps Script에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 주소는 바뀌지 않습니다.
